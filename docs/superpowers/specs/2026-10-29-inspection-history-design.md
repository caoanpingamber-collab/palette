- 保存原图、原视频和当次检测结果；视频分别保存首帧、尾帧的结果。
- 不推断提交人身份，也不声称能按同学姓名筛选。
- 扩展原项目 `/Users/bytedance/Documents/claude/palette-app`，不复制项目，不改背景效果和检测算法，不回退其他会话的改动。

## 现状与实施范围

当前是 Vite + React，没有后端和数据库。结果只在页面内存中，原视频使用临时 Blob URL，无法靠保留 URL 字符串恢复素材。帧结果含浏览器运行时对象，不能整包直接序列化。

本轮新增后端、持久存储和管理员后台，在原项目中完成本地验证。不发布、不创建云账号、不把公司素材发送到新外部平台。上线的存储位置、域名和权限另行确认。本地功能完成不意味着已发布网页开始积累数据。

## 匿名前台

- 检测仍在浏览器执行；完成检测后自动归档一次，通过与不通过均保存。
- 用户后续要求保持原页面 UI：不增加历史入口、归档说明、保存状态或重试控件；管理后台仅通过 `/admin` 访问。
- 归档静默执行；失败仅记录浏览器控制台警告，不阻塞现有检测、视频播放和导出，不将失败伪称为保存成功。
- 使用稳定提交 ID 防止重试造成重复记录；不承诺刷新页面后恢复尚未完成的上传。
- 读取或解码失败不算正常检测历史。已经丢失的历史无法补回，只从功能启用后开始积累。
- 前台不能查询历史、浏览素材或删除任何记录，不添加公开个人历史页。

## 管理员

- `/admin` 单独登录，后端鉴权，单管理员账号，不开放注册。
- 列表默认时间倒序：缩略图、文件名、类型、时间、通过状态和失败项。
- 文件名搜索、日期范围、图片/视频、通过/不通过筛选，服务端分页。
- 详情显示原图或可播放的原视频、当次指标、调色板、建议、规则版本。
- 视频持续循环播放，首尾帧切换仅切换检测详情，不冻结视频。
- 支持下载原文件、导出当次报告；删除需明确提示不可恢复并确认，同时删除关联原文件、帧图、缩略图和记录。
- 不包含飞书登录、人员识别、多管理员、人工复核或版本对比。

## 保存数据

记录 ID、检测时间、服务端入库时间、文件名、类型、字节数、摘要；总通过状态、各项指标与结论、失败项、建议和调色板；检测规则快照/版本、归档结构版本、可用时的前端构建版本。

图片保留原文件及栅格缩略图；视频保留原 MP4、首尾帧图与各自结果。临时 URL、HTMLImageElement、像素缓冲不入库，恢复详情时重建必要运行时对象。

回看旧记录使用保存的快照，不按新规则重算或覆盖。结果来自前台检测，归档不是服务端独立复核，不宣称不可篡改审计。

## 实施方建议，待批准

- 在现有项目增加 Node 后端，本地 SQLite 存结构化数据，私有文件目录存素材；均不放 public、dist 或 Git 中。
- 通过稳定接口隔离前端与存储。重启后端、清除浏览器缓存、换浏览器不删除服务端记录。
- 本地磁盘方案仅用于本地验证，不当作 Vercel 等环境的生产持久化方案。上线需另接可靠的数据库与私有文件存储，不依赖临时运行目录。
- 首版默认不自动删除已完成的历史和素材，仅由管理员明确确认后删除。自动过期清理不属于本轮，后续如需增加须单独确认保留期。后台显示当前存储占用和容量限制。
- 设置单文件、请求体、提交频率、总存储容量上限；超限明确提示归档失败，不阻塞检测，也不偷偷删除未到期记录。
- 管理员通过本地初始化命令设置账号和密码，不需要在聊天中提供口令；成熟密码哈希、服务端会话、HttpOnly Cookie、退出和过期、登录限速；生产 HTTPS + Secure Cookie。

## 安全与一致性

- 匿名只能提交新归档；列表、详情、原文件、报告及删除均需管理员权限。不能只靠前端隐藏路由。
- 原文件无公开匿名链接，读取响应禁止公共缓存。管理员更改数据需 CSRF 防护和请求来源校验。
- 服务端生成存储文件名，不用上传文件名拼接路径；验证实际类型和字节数，不执行上传内容。预览使用安全栅格图，SVG 等主动内容仅作附件下载。
- 文件和记录作为同一个提交单元。上传中断或数据库失败清理未完成的暂存数据，重试不重复，管理员删除可安全重试；清理暂存不得影响已完成的归档。
- 凭据、会话和密钥不进前端构建、Git 或日志；本地限流不能被宣传成分布式生产限流。
- 保留现有工作区的 PatternRefraction、color.js、vite.config.js 改动，接入时只合并必要代码。

## 验收

- 图片/MP4、通过/不通过均归档一次，重启后仍能查看原素材和检测快照。
- 视频首尾帧指标对应、持续播放，规则更新不修改旧记录。
- 匿名与过期会话不能读取、导出、删除；搜索、分页、空状态和错误状态可用。
- 上传中断、超限、保存失败、重试、删除无虚假成功或遗留暂存文件；容量不足不能自动删除旧归档。
- 现有检测、背景、预览、标签、阈值、下载不回退；完成测试与代码审查，启动本地服务供用户验收。
