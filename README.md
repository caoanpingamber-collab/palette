# CapCut Banner 体检工具

项目位置：`/Users/bytedance/Documents/claude/palette-app`。

这是用于 CapCut 首页 Banner 物料检查的本地 Web 工具，支持上传 800×1296 图片或 MP4，检查尺寸、标题对比度、卡片边缘、主体位置、主体外显著前景，并导出检测报告。

## 使用

```bash
npm install
npm run dev
```

历史单文件版本保存在 `archive/`。以后更新以这个 Claude 文件夹下的项目为准，不再使用桌面目录。

交付状态、源码范围和接手步骤见 [DELIVERY.md](DELIVERY.md)。当前源码交付不等于云端历史功能已经在发布网站上线。

## 检测历史与管理员后台

归档默认关闭，需明确配置存储后开启。当前支持妙搭云数据库和私有对象存储；云端失败时不回落到本机素材目录。前台不增加 UI，也不要求同学登录。已有本地数据不会自动删除。

### 妙搭云端接入（当前本地网站）

开发用资源由操作员通过 `HISTORY_MIAODA_APP_ID` 配置，不随公开源码分发私密环境。`.env.local` 配置 `HISTORY_STORAGE=miaoda`；归档默认保持 `HISTORY_ARCHIVE_ENABLED=false`，只有所选环境完成验证后才可开启。数据库保存记录、管理员密码哈希和会话；私有对象存储保存原素材、帧图与缩略图，下载通过管理员鉴权接口，不把签名地址或凭据返回前台。

服务端使用官方 `lark-cli` SQL 网关与 FileService SDK，不裸连数据库。需要本机已安装并授权 `lark-cli`；短期开发凭据仅存于 `.history-data/miaoda-runtime/.env.local`，已被 Git 和 Vite 排除。凭据到期后服务停止云端读写，不会悄悄改为磁盘保存。通过以下命令刷新，存储适配器会重新读取凭据：

```bash
node scripts/miaoda-refresh.mjs
```

首次接入运行 `node scripts/miaoda-setup.mjs`。仅在云端尚无账号时迁移现有管理员密码哈希，不读取明文密码；如果发现本地已有检测档案或云端账号不同，会停止，不擅自覆盖。既有本地 SQLite 保留，但云端模式不再读写它。

开发连接器服务于本地 5190 网站及其 5192 API；归档关闭时不会保存检测素材，也不等于更新或发布了妙搭上的静态网站。开发凭据不能用于生产托管，`NODE_ENV=production` 会拒绝此连接方式。已有平台原生云端运行时的部署与合成测试记录，但网站接入、在线管理员页面和登录权限隔离尚未完成验收；不能把开发 CLI 搬到生产环境冒充完成，也不能把申请公司域名当成已证实的前置要求。

存储总额度、保留策略及收费尚未确认。应用默认 1 GiB 是自身的写入保护上限，不是妙搭提供的免费容量承诺。并发写入以云端事务锁预留容量；删除先落防重放标记，再清理对象。服务启动或新提交时，会恢复明确处于删除中的记录和超时 15 分钟的未完成预留，不清理已完成档案。

运行环境需要 Node.js 22.13 或更新版本（使用内置 SQLite）。

```bash
npm install
npm run dev
```

`npm run dev` 同时启动网页（默认 5190）和本机历史 API（默认 5192）。网页端口被占用时 Vite 会选下一个空闲端口；不要关闭其他项目的服务。

只有新环境尚无管理员时，才在交互式终端运行以下命令，设置管理员账号与至少 12 位的密码，输入密码不会回显。接手已有环境时保留现有账户，不要无意重置密码，也不需要把密码发到聊天中。

```bash
npm run admin:create
```

管理员只通过 `/admin` 登录，首页不增加入口或说明。普通同学无需登录；只有存储已配置并启用归档时，检测后才会静默保存原文件、缩略图和当次结果，视频保留原 MP4 和首尾帧的独立结果。关闭时不生成归档帧或上传素材。原页面不显示保存状态、错误或重试控件；启用后的归档失败仅记录浏览器控制台警告，不影响检测与导出，历史以实际成功入库为准。匿名用户无法读取历史和素材，也不能删除记录。

后台支持文件名、类型、通过状态、本地日期范围筛选与分页；详情可查看原图、循环播放原视频、切换首尾帧检测结果、下载原文件、导出报告。历史使用当次规则与结果快照，不随新规则重算。无法补回功能启用前未保存的检测。

### 数据保留与配置

仅在显式使用本地存储实现时，SQLite、管理员密码哈希、会话与私有素材位于项目的 `.history-data/`。妙搭模式不向此处写入检测记录或素材，只保存服务端开发凭据。默认归档容量 1 GiB，不自动删除已完成记录；超限时拒绝归档。管理员确认删除后，原文件、帧图与记录一并删除。

删除后只保留提交 ID 与删除时间作为防重放标记，不含文件名、素材或检测结果，防止网络迟到重试把已删除素材重新恢复。

需要修改端口或容量时参考 `.env.example`，配置放入 `.env.local`，不能放入前端的 `VITE_*` 变量。私有数据目录只能使用 `.history-data/` 或项目外专用目录，不能放进 `public/`、`dist/`、`src/` 等可公开目录，软链接也会检查真实路径。新目录必须为空，服务用所有权标记保护已有的无关目录。备份需先停止服务，再完整备份私有数据目录（包括所有权标记与 SQLite 的 WAL 文件）；素材与数据库应一起备份和恢复。

本地每个来源 IP 每小时最多提交 60 次，最多同时处理 4 个上传，请求上限 9 MiB；原图仍限制 300 KB，原视频 500 KB。预览帧上限 4 MiB，缩略图上限 128 KiB。登录也有限速。反向代理默认不受信任，生产需另配置可靠的共享限流，不能把本地限流当成分布式防护。

### 运行与发布边界

现有本地网站已支持云端存储连接；线上静态发布版仍未更新。真实云端验证只使用合成素材，验证后清理测试记录和对象。仅发布 `dist/` 到静态托管不能提供历史后台；没有 API 时不会伪装归档成功，前台也不新增提示 UI。

后续上线需经确认接入持久数据库与私有文件存储、HTTPS、管理员凭据和准确的 `HISTORY_ALLOWED_ORIGINS`。本地 SQLite/磁盘实现要求单实例持久磁盘，不能直接部署到无持久磁盘的函数环境，也不要用多个实例共写此目录。原文件不设公共访问链接，素材读取依赖管理员会话。

现有工具链及其传递依赖仍有 `npm audit` 告警，本轮未强制升级无关依赖；本地功能测试不代表生产安全评估。公开发布前需单独处理或评估这些告警。删除为应用级删除，不承诺取证级安全擦除或备份中的同步销毁。

如使用持久磁盘的独立服务器，构建后 `NODE_ENV=production npm start` 会同时提供 `dist/` 与 API；生产模式要求配置准确的 HTTPS 来源，Cookie 自动使用 Secure。对外发布仍需单独检查反向代理、备份、容量与安全配置。
